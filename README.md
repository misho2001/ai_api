========================================================================
                      GOOGLE GEMINI API - JAVA INTEGRATION
========================================================================

OVERVIEW
--------
This project demonstrates how to connect to Google's Gemini AI models 
using Java. It allows you to send prompts, generate text responses, and 
process AI output directly inside a Java application.


PREREQUISITES
-------------
1. Java Development Kit (JDK 11 or higher).
2. A Google Gemini API Key:
   - Get your free key from Google AI Studio (https://aistudio.google.com).
3. Build Tool: Maven or Gradle.
